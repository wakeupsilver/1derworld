# Color Code Experiment 1 — Desk Arcade

A browser game that uses a document camera to turn everyday objects and marker drawings into game levels. Colors are mapped to meanings (solid ground, bounce pad, lava, coin, goal).

Modes: **Runner** (platformer) and **Marble Run**.

## Run

```
python3 -m http.server 8765
```

Then open http://localhost:8765 (camera access requires localhost or HTTPS).
